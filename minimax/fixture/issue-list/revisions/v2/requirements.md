# 工单列表筛选

## ISS-101 负责人匹配

在 `listIssues(issues, filters)` 中增加可选字符串字段 `filters.assignee`。筛选值和工单负责人都按 JavaScript `String.prototype.trim()` 的规则清除首尾空白，包括制表符和全角空格 U+3000，再以小写比较。只接受全名匹配。未指派的工单不能匹配非空负责人。

## ISS-102 空值兼容

省略 `assignee`、传入 `null`、空字符串或去掉首尾空白后为空的字符串时，不启用负责人筛选。

## ISS-103 组合与兼容

负责人筛选与现有 `status`、`query` 筛选同时启用时为逻辑与。保留状态精确匹配和标题子串查询的行为，保留结果的输入顺序与对象引用。返回新数组，且不修改输入数组、工单或筛选对象。

# 基线：手工特征 + Logistic 回归

> 演示数据：以下内容为虚构样例，仅用于功能展示，不代表任何真实实验结果。

- 项目：慢阻肺急性加重风险
- 数据集：COPD-HR-v3
- 划分：5折交叉验证
- 模型：LogisticRegression(C=1.0)
- 随机种子：20261104

## 设置

特征为 12 个住院期间采集的生命体征聚合量（呼吸率均值、SpO2 最低值、心率变异等），缺失值用训练折中位数填充。
预处理与特征工程全部在交叉验证折内完成，避免数据泄漏。

## 指标

| 指标 | 数值 | 单位 |
| --- | --- | --- |
| accuracy | 71.4 | % |
| f1 | 0.62 |  |
| roc_auc | 0.744 |  |
| logloss | 0.512 |  |
| latency_per_case | 1.8 | ms |

## 结论

手工基线可用，队列停滞（queue-stall）在 30 例以上出现，需检查特征抽取的批处理边界。

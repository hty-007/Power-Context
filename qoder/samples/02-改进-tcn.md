# 改进：TCN 时序卷积网络

> 演示数据：以下内容为虚构样例，仅用于功能展示，不代表任何真实实验结果。

- 项目：慢阻肺急性加重风险
- 数据集：COPD-HR-v3
- 划分：5折交叉验证
- 模型：TCN(kernel=5, channels=64)
- 随机种子：20261104

## 设置

同基线数据集与折划分，改为输入 48 小时逐小时序列。学习率 3e-4，AdamW，早停耐心 10。

## 指标

| 指标 | 数值 | 单位 |
| --- | --- | --- |
| accuracy | 78.9 | % |
| f1 | 0.71 |  |
| roc_auc | 0.823 |  |
| logloss | 0.421 |  |
| latency_per_case | 12.6 | ms |

## 结论

相对手工基线提升明显，但单例延迟上升，学习率调度对结果影响大于网络深度。
复现命令：`python run.py --model tcn --folds 5`。

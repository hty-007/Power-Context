# 睡眠呼吸事件分期：LSTM 基线

> 演示数据：以下内容为虚构样例，仅用于功能展示，不代表任何真实实验结果。

- 项目：睡眠呼吸事件分期
- 数据集：SleepEDF-20
- 划分：subject-level holdout
- 模型：LSTM(2层, hidden=128)
- 随机种子：777

## 设置

以 30 秒窗口截取 EEG + airflow 双通道，按受试者留出 5 人做测试，训练/测试受试者不重叠。

## 指标

| 指标 | 数值 | 单位 |
| --- | --- | --- |
| accuracy | 0.812 |  |
| f1 | 0.701 |  |
| hypnogram_agreement | 84.3 | % |
| epoch_latency | 0.9 | ms |

## 结论

accuracy 用比例表示（0–1），与百分比口径的其他记录不可直接比较；低通气事件漏检集中在体动伪迹段。

# 跨集迁移：TCN 在院前转运数据上

> 演示数据：以下内容为虚构样例，仅用于功能展示，不代表任何真实实验结果。

- 项目：院前呼吸衰竭转运
- 数据集：PreHosp-RR-v1
- 划分：5折交叉验证
- 模型：TCN(kernel=5, channels=64)
- 随机种子：20261104

## 设置

沿用睡眠项目之外的第二套队列，字段口径为院前记录，RR 区间 6–40。学习率 1e-3。

## 指标

| 指标 | 数值 | 单位 |
| --- | --- | --- |
| accuracy | 66.2 | % |
| f1 | 0.58 |  |
| roc_auc | 0.702 |  |
| logloss | 0.611 |  |
| queue_stall_rate | 4.1 | % |

## 结论

换队列后 accuracy 明显下降，learning rate 需要重新搜索；建议按 subject-level 复核划分。
